하루 사용 안내

설치와 인터넷 연결 없이 사용하는 개인 업무 캘린더입니다. HTML 파일을 Edge 또는 Chrome에서 열어 주세요.

  1. 새 JSON 만들기로 저장할 파일을 만들거나, 파일 선택으로 기존 일정 파일을 연결하세요.
  2. 일정을 저장하거나 완료 체크하면 연결한 JSON에 자동 저장합니다. 하단의 파일 저장 상태를 확인하세요.
  3. 다음 실행 시 연결을 복원합니다. 브라우저 정책에 따라 접근 허용을 다시 눌러야 할 수 있습니다. HTML 파일의 위치·이름이나 브라우저를 바꾸면 다시 선택해야 할 수 있습니다.
  4. 상단에서 제목·메모, 기간, 분류, 상태를 검색하세요. 기간은 일정과 겹치는 날짜를 찾으며, 비우면 전체 기간입니다.
  5. 같은 JSON 파일은 한 창에서 편집하세요. 다른 창이나 프로그램의 변경이 감지되면 자동 저장을 중단합니다.

JSON 백업은 현재 내용을 별도 파일로 내려받습니다. 파일 직접 저장이 지원되지 않으면 JSON 불러오기 / JSON 백업으로 이용할 수 있습니다. 브라우저 임시 보관은 파일 백업을 대신하지 않습니다. 알림과 공휴일 자동 조회는 포함되어 있지 않습니다.

잘못된 JSON은 불러오지 않습니다. 파일 변경·복원 전에는 필요에 따라 백업하세요. 일정 데이터의 외부 전송 기능은 없습니다.
